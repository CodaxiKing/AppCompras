Controle de Compras Mensais
Um aplicativo desenvolvido em React Native para simplificar e organizar suas compras mensais, ajudando você a economizar tempo e dinheiro.

📝 Descrição
Este projeto foi criado para ser um assistente pessoal nas idas ao supermercado. Com ele, é possível criar listas de compras detalhadas, acompanhar os gastos em tempo real e manter um histórico de compras para melhor planejamento financeiro. A interface intuitiva e as funcionalidades inteligentes tornam a experiência de compra mais eficiente e agradável.

✨ Funcionalidades
Listas de Compras Múltiplas: Crie e gerencie diversas listas para diferentes necessidades (mercado, farmácia, etc.).

Adição Rápida de Itens: Adicione produtos com facilidade, especificando quantidade, unidade de medida e preço.

Cálculo em Tempo Real: O aplicativo calcula o subtotal da sua compra à medida que você adiciona itens ao carrinho.

Histórico de Compras: Mantenha um registro de suas compras anteriores para consulta e planejamento.

Sugestão de Itens: Com base em seu histórico, o app pode sugerir itens que você costuma comprar.

Status de Itens: Marque os itens como "no carrinho" ou "comprado" para um melhor controle.

🚀 Tecnologias Utilizadas
Este projeto foi desenvolvido com as seguintes tecnologias:

React Native | Expo | TypeScript | AsyncStorage (para armazenamento local)

📦 Instalação e Execução
Para rodar este projeto localmente, siga os passos abaixo:

1. Clone o repositório:

Bash

git clone https://github.com/seu-usuario/nome-do-repositorio.git

2. Navegue até o diretório do projeto:

Bash

cd nome-do-repositorio

3. Instale as dependências:

Bash

npm install


4. Inicie o servidor de desenvolvimento:

Bash

npx expo start

Após iniciar o servidor, um QR Code será exibido no terminal. Escaneie este QR Code com o aplicativo Expo Go (disponível para Android e iOS) no seu celular.
